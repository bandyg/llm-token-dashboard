# 01 Idea Brief

> Template v2

## 一句话价值

本地桌面端 LLM 多家额度统一监控面板

## 目标用户

- 同时混用多家 LLM 厂商（含无官方 API 的网页端服务）的重度个人用户

- 跑自动化脚本 / 多账号轮询的小团队开发负责人

- 需要量化 LLM 成本、防止超额停服的独立开发者

## 解决什么问题

用户在多家 LLM（含无 API 的纯网页端 Provider）混用时，需逐个登录厂商后台查询已用与剩余额度，操作繁琐、易遗漏导致超额停服。本工具通过统一 Dashboard 实时聚合所有 Provider 用量、剩余额度与告警，彻底告别手动巡检。

## 成功的样子

- 用户一次拖框配置后，所有 Provider（含纯网页端）额度在一屏 Dashboard 统一呈现，已用 / 剩余 / 趋势一目了然

- BrowserView 叠层选区 UI 支持所见即所得拖框，坐标自动回填并持久化，终身复用、零手填

- 任意 Provider 采集失败红字醒目标注 + 一键定位，同时支持 ≤3 次点击手动录入兜底，永不丢数据

- 额度阈值可配置告警，历史用量以折线 / 柱状图呈现趋势，提前预判超额风险
