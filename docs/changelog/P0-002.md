# P0-002 区域选择器拖拽框选 — 验收证据

> **本轮（2026-10-10 v4）用户实测反馈两条流程缺陷返工**：
> ① **登录墙死路**——未登录打开区域浏览器时，框选画布（z-index 9999）拦截全部鼠标事件，
>    用户无法在登录墙页面输入凭据，也没任何登录引导；现 `openRegionBrowser` 前置 `checkAuth`：
>    未登录 **不注入画布**（页面保持可交互，直接登录），宿主地址栏出现「🔐 我已完成登录」按钮，
>    点击后主进程复核登录态（新通道 `llm:region:recheck`）→ 已登录自动回目标页注入画布。
> ② **「取消」不退出**——画布工具抽屉「取消」此前只移除画布 DOM，BrowserView 仍附着窗口中部
>    遮挡宿主表单且宿主状态不同步；现「取消」经新通道 `llm:region:exit` 通知主进程解除附着，
>    并广播 `region-browser-closed` 使宿主页复位（关闭按钮消失、占位说明恢复）。
> ③ **粘性 toast 遮挡控件**（随用例暴露）——`.toasts` 容器改 `pointer-events: none`（toast 本体保留
>    交互），登录引导降为 info 级自动消失，不再挡住工具栏按钮。
> 新增 e2e 2 条（登录墙引导 6.0s / 取消复位 20ms），全量回归：单元 71/71、e2e 38/38、typecheck 0 错误。
