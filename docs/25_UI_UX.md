# 25 UI/UX

> Template v2

## 全局视觉风格

- **配色体系**：主色 `#2D7FF9`（操作主蓝，用于按钮、链接、选中态）；辅色 `#6B7280`（次级文本/分割线）、`#F3F4F6`（卡片底）；语义色 4 档——成功 `#10B981`、警告 `#F59E0B`、危险 `#EF4444`、信息 `#3B82F6`；背景层级 3 档——`#FFFFFF`（卡片）、`#F9FAFB`（主背景）、`#111827`（深色模式画布，可由用户在设置中切换）。

- **字体层级**：全局基线 14px，等宽字体仅用于坐标、数值、testid 调试面板（`JetBrains Mono, Consolas, monospace`）；标题 H1 20px / H2 16px / H3 14px；正文 14px；辅助说明 12px `#6B7280`；监控数字使用 24px Semibold 强化可读性。

- **间距体系**：基础单位 4px，常用档位 4 / 8 / 12 / 16 / 24 / 32；卡片内边距统一 16px；区块间距 24px；左右主边距 24px。

- **组件风格**：圆角统一 6px（控件）/ 8px（卡片）/ 4px（Tag）；阴影仅 2 档——`0 1px 2px rgba(0,0,0,.06)`（卡片默认）、`0 8px 24px rgba(0,0,0,.12)`（弹窗/抽屉）；描边 `1px solid #E5E7EB`；按钮三态——默认 / Hover（背景 +4% 亮度）/ Disabled（背景 `#F3F4F6`、文字 `#9CA3AF`）。

## 界面清单

### 界面：主窗口（Dashboard）

- **入口与跳转**：应用启动后默认进入；从托盘图标单击唤起；从「设置」「历史趋势」点击左上角 Logo 或按 `Cmd/Ctrl+1` 返回。

- **布局区块**：顶部固定 56px 应用栏（左侧 Logo + 应用名，中间搜索框 `testid=topbar-search`，右侧同步刷新按钮 + 设置入口）；左侧 240px 侧边栏（导航项：Dashboard / 提供商配置 / 区域选择器 / 告警 / 历史 / 设置）；右侧自适应主区，上下分布——上半 Provider 卡片网格，下半「今日用量概览」横向条形图。

- **元素清单**：

- Provider 卡片：宽自适应、高 140px，包含厂商名、状态点（绿/黄/红/灰）、已用/总额度进度条、最近一次抓取时间、刷新按钮 `testid=card-refresh-{providerId}`、编辑按钮 `testid=card-edit-{providerId}`。

- 进度条：背景 `#E5E7EB`，填充按使用率切换——<60% 主蓝、60–85% 警告橙、>85% 危险红，文本显示「已用 $12.34 / $50.00（25%）」。

- 同步刷新按钮 `testid=topbar-sync-all`：下拉菜单可选「刷新全部」「仅刷新失败的」「刷新选中」。

- **交互行为**：单击卡片 → 弹层显示 7 天趋势迷你图；双击卡片 → 跳转「提供商详情」；进度条悬浮 → Tooltip 显示重置时间；快捷键 `R` 触发全量同步；右键卡片 → 上下文菜单（立即刷新 / 编辑配置 / 禁用 / 删除）。

- **三态**：

- 空态：未配置任何 Provider，居中插画 + 「还没有配置任何 LLM 提供商，点击右上角添加」+ 主按钮「添加 Provider」`testid=empty-add-provider`。

- 加载态：顶部进度条 `testid=topbar-progress` 显示「正在同步 3/8」；卡片骨架屏占位。

- 错误态：失败卡片整体红色描边 `1px solid #EF4444`，标题区下方一行红字 `testid=card-error-msg` 显示具体原因（如「DOM 选择器失效」/「OCR 失败：图片加载超时」），右侧红字按钮「手动录入」`testid=card-manual-entry`。

- **边界情况**：Provider 数量超过 12 时启用虚拟滚动；网络断开时顶部黄色横幅 `testid=banner-offline`「网络不可用，仅显示缓存数据」；权限缺失（macOS 辅助功能/截图权限）时启动时弹权限引导。

### 界面：提供商配置（列表 + 新增/编辑弹窗）

- **入口与跳转**：侧边栏「提供商配置」入口；Dashboard 卡片「编辑」按钮；新增按钮位于列表右上 `testid=provider-add`。

- **布局区块**：左侧 280px 厂商模板列表（内置 OpenAI / Anthropic / Google / 智谱 / DeepSeek / 通义千问 / 文心一言 / 小米 MiMo / MiniMax / OpenCode / Ollama / 自定义）；右侧详情编辑区，按 Tab 切分「基本信息 / 凭据 / 抓取方式 / 区域选择」四页。

- **元素清单**：

- 抓取方式 Tab 单选组：`testid=capture-mode` 选项——① 官方 API（自动）② BrowserView DOM 抓取 ③ BrowserView OCR 抓取 ④ 仅手动录入。

- 凭据区：API Key 字段 `testid=cred-apikey`（带「显示/隐藏」眼睛图标与「测试连接」按钮）、Base URL（可选）、代理设置。

- DOM 抓取配置：URL `testid=dom-url`、登录态 cookie 导入按钮、选择器列表（每行：名称 + CSS 选择器 + 「在预览中高亮」按钮 + 删除）。

- **交互行为**：选择厂商模板后自动填充默认字段；测试连接成功显示绿色对勾 + 返回账号信息预览；保存后立即执行一次抓取以验证配置；快捷键 `Cmd/Ctrl+S` 保存，`Esc` 关闭。

- **三态**：

- 空态：首次进入显示引导「选一个厂商模板开始配置」并提供「自定义」选项。

- 加载态：测试连接按钮转圈 + 禁用；保存按钮显示 spinner。

- 错误态：API Key 错误红字「凭据无效 (401)」；选择器未匹配红字「选择器在当前页面未找到元素」并附「打开浏览器调试」按钮。

- **边界情况**：自定义厂商凭据区隐藏 OAuth 流程相关字段；粘贴的 API Key 自动 trim 空白；测试连接超时 10s 后弹窗询问「继续等待」或「跳过」。

### 界面：BrowserView 区域选择器（产品记忆点核心）

- **入口与跳转**：提供商配置 → 「抓取方式」选「BrowserView DOM/OCR」→ 切到「区域选择」Tab → 点击「打开浏览器捕获」按钮 `testid=region-open-browser`；也可从 Dashboard 卡片右键菜单「重新选择区域」进入。

- **布局区块**：主窗口内嵌 BrowserView 占满中部（上方 48px 地址栏 + 加载指示，下方全屏网页内容）；BrowserView 上方叠一层 100% 透明的画布（HTML5 `<canvas>` 或 SVG overlay，`position: absolute; inset: 0; pointer-events: auto`，`z-index: 9999`）；画布之上浮一个右侧工具抽屉 320px（默认半收起，点击展开），抽屉内含「新建选区」「清空」「保存」「取消」四按钮 + 已有选区列表。

- **元素清单**：

- 选区可视化矩形：边框 `2px dashed #2D7FF9`，填充 `rgba(45,127,249,0.15)`，四角 + 四边中点共 8 个 8×8px 实心白色圆点拖拽手柄 `testid=region-handle-{n}`，中心显示坐标标签 `{x},{y} {w}×{h}`。

- 工具抽屉列表项：每行显示选区名称 + 缩略图（80×60）+ 「定位 / 编辑 / 删除」三按钮 `testid=region-row-actions-{id}`。

- 底部状态栏：实时显示鼠标坐标 `testid=overlay-coord` 与当前选区数量 `testid=overlay-count`。

- **交互行为**：

- **新建选区**：鼠标在画布变为十字光标 `cursor: crosshair`，按住左键拖出矩形，松开瞬间矩形进入「编辑态」（8 手柄可调），右上方自动弹出命名输入框 `testid=region-name-input`，回车确认。

- **编辑选区**：单击矩形进入编辑态；拖拽手柄单边缩放；拖拽矩形本体平移；按住 `Shift` 等比缩放；按住 `Alt` 以中心为锚点缩放；`Delete` 删除当前选区；`Esc` 退出编辑态。

- **多选与对齐**：按住 `Shift` 单击可多选矩形，工具抽屉出现「左对齐 / 顶对齐 / 等宽 / 等高」按钮组。

- **坐标持久化**：每次矩形变化（拖拽/缩放）触发防抖 300ms 写入 IndexedDB `regions` 表，字段 `{ providerId, name, x, y, w, h, mode: 'DOM'|'OCR', selector?, lastModified }`；保存按钮 `testid=region-save` 触发全量校验与回写到 Provider 配置。

- **一键复用**：从抽屉列表点击「定位」按钮，浏览器自动滚动并黄色脉冲高亮对应矩形 3 次。

- **三态**：

- 空态：首次进入显示蓝色提示条 `testid=overlay-hint`「按住鼠标左键拖拽框选需要监控的区域」+ 中央浮动引导箭头指向画布。

- 加载态：地址栏右侧 spinner + 加载百分比；画布层 `pointer-events: none` 防止误操作。

- 错误态：跨域 iframe 内无法注入画布时，红色横幅「此页面包含跨域框架，区域选择不可用，请使用桌面客户端登录」+ 提供「降级为整页 OCR」一键切换按钮。

- **边界情况**：选区最小尺寸限制 10×10px；超出视口自动夹紧；DPI 缩放 >100% 时坐标按物理像素存储、渲染时按 CSS 像素换算并标注「缩放系数 1.25」；超长页面支持中间滚轮截断（画布高度等于 `document.body.scrollHeight` 而非视口高度），并出现右侧缩略导航条。

### 界面：手动录入兜底弹窗

- **入口与跳转**：Dashboard 失败卡片「手动录入」按钮；全局快捷键 `Cmd/Ctrl+M`；告警通知中心「录入用量」跳转。

- **布局区块**：居中模态 480×420px；顶部标题栏「为 {ProviderName} 手动录入用量」+ 关闭 X；中部表单（金额模式 / Token 模式切换 Segmented Control + 数值输入 + 时间选择 + 备注）；底部按钮组「取消」「保存并继续」「保存」`testid=manual-save`。

- **元素清单**：

- 模式切换 `testid=manual-mode`：选项「已用金额」「已用 Token（输入/输出分列）」。

- 数值输入 `testid=manual-amount`：带千分位格式化，失焦校验非负。

- 时间选择 `testid=manual-time`：默认 `now`，可改具体到分钟，存为 ISO 字符串。

- 「保存并继续」按钮触发保存后清空表单并保持弹窗，方便连续录入。

- **交互行为**：保存后立即在 Dashboard 卡片反映新数据并把失败状态置为「手动覆盖」绿色徽标；`Esc` 关闭；`Enter` 提交。

- **三态**：

- 空态：首次进入显示「最后一次同步失败时间」提示。

- 加载态：保存按钮 spinner。

- 错误态：负数、超大值（> 总额度 10 倍）弹红色 Toast「数值异常，请确认」。

- **边界情况**：批量录入支持粘贴「时间,金额」CSV 多行解析；时区按系统本地时区存储，展示按用户设置时区换算；离线模式下录入仍可用，恢复网络后不入云（仅本地）。

### 界面：告警与阈值设置

- **入口与跳转**：侧边栏「告警」入口；Dashboard 右上铃铛 `testid=topbar-alerts` 红点徽标。

- **布局区块**：左侧阈值规则列表（每条规则卡片：触发条件 + 通知渠道 + 启用开关）；右侧「通知渠道」Tab（系统通知 / Webhook / 邮件）。

- **元素清单**：

- 规则条件三选：百分比阈值（≥80%）、绝对金额阈值（≥$10）、剩余时间不足（如 7 天内将耗尽）。

- 通知渠道开关 `testid=alert-channel-{type}` + 测试按钮。

- **交互行为**：新增规则弹抽屉；启用/禁用实时生效；点击铃铛弹出通知中心抽屉，最近 30 条记录。

- **三态**：空态显示「还没有告警规则，添加一条试试」；加载态骨架屏；错误态（Webhook 失败）显示红色「最近失败：HTTP 500」并提供「重试 / 编辑」。

- **边界情况**：触发后 30 分钟内同一规则不重复通知；跨午夜自动重置「每日额度」类规则。

### 界面：历史趋势

- **入口与跳转**：侧边栏「历史」入口；Dashboard 卡片双击进入对应 Provider 趋势。

- **布局区块**：顶部时间范围选择器（今日 / 7 天 / 30 天 / 自定义）；左侧 Provider 多选树；主区折线图（按金额与 Token 双 Y 轴切换）；下方明细表格。

- **元素清单**：图表悬浮十字线 + Tooltip；表格列：时间、Provider、模式（API/DOM/OCR/手动）、用量、操作（编辑手动条目）。

- **交互行为**：Shift+滚轮横向缩放时间轴；双击数据点跳转到该时刻详情；右键导出 CSV/JSON。

- **三态**：空态「选择时间范围开始查看」；加载态图表骨架；错误态某天缺失显示断线 + 悬浮「数据采集失败，点击重试」。

- **边界情况**：超过 90 天数据按周聚合；表格支持虚拟滚动 10000+ 行。

### 界面：设置（偏好）

- **入口与跳转**：侧边栏「设置」；Dashboard 右上齿轮。

- **布局区块**：左侧分类导航（通用 / 同步 / 隐私 / 关于）；右侧表单区。

- **元素清单**：通用（主题、深色模式、字体大小、时区）；同步（默认刷新间隔 5min、最低 1min、最高 60min、仅手动开关）；隐私（本地数据存储路径、清除缓存按钮、导出/导入配置）。

- **交互行为**：所有改动即时生效并标灰点「未保存」；底部固定「保存」「恢复默认」按钮组；`Cmd/Ctrl+,` 打开。

- **三态**：首次进入显示当前生效值；加载态从主进程拉取配置 spinner；错误态（写配置失败）弹错误 Toast 并阻止关闭。

- **边界情况**：导入配置校验版本号，不兼容弹迁移向导；路径非法显示红色「目录不存在」并提供「创建目录」。

## 全局交互规则

- **键盘可达性**：所有按钮、输入框、卡片支持 `Tab` 顺序遍历，焦点环 `2px solid #2D7FF9` + 2px offset；主导航快捷键 `Cmd/Ctrl+1..6`；全局快捷键 `Cmd/Ctrl+R` 刷新、`Cmd/Ctrl+F` 搜索、`Cmd/Ctrl+,` 设置、`Esc` 关闭弹窗/退出选区编辑态；区域选择器内自定义快捷键：`Arrow` 1px 移动、`Shift+Arrow` 10px 移动。

- **焦点管理**：模态弹窗打开时焦点锁定在弹窗内，关闭后归还触发元素；抽屉类不锁焦点但 `Shift+Tab` 在首个元素循环；Dashboard 卡片刷新后焦点不重置；区域选择器保存成功后焦点跳到新建选区按钮以便连续操作。

- **Toast / 确认弹窗约定**：Toast 4 档——info（蓝，3s 自动消失）、success（绿，2s）、warning（黄，5s、不消失需手动关闭）、error（红，7s、含「查看详情」链接）；位置右上堆叠，最多 3 条，超出排队；确认弹窗仅用于「不可逆操作」（删除 Provider、清空全部历史、恢复默认配置），普通操作采用内联确认或 Undo Toast（5s 内可撤销，撤销按钮 `testid=toast-undo`）。

- **红字失败统一规范**：所有抓取失败文案以「❌ {ProviderName}」开头，后接具体原因 + 解决方案快捷链接（测试连接 / 重新选择区域 / 手动录入），颜色 `#EF4444`，字号 12px，位置紧贴失败卡片标题下方，确保 3 次点击内（卡片 → 失败原因 → 手动录入按钮）完成兜底录入。
